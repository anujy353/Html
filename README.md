## 📚 Topics Covered

### 1. Heading Tags

HTML provides six heading levels, from `<h1>` to `<h6>`.

* `<h1>` – Defines the highest-level heading.
* `<h2>` – Defines a second-level heading.
* `<h3>` – Defines a third-level heading.
* `<h4>` – Defines a fourth-level heading.
* `<h5>` – Defines a fifth-level heading.
* `<h6>` – Defines the lowest-level heading.

### 2. Paragraph Tag

* `<p>` – Defines a paragraph of text.

### 3. Image Tag

* `<img>` – Embeds an image into a web page.
* Important attributes: `src` and `alt`.

### 4. Anchor Tag

* `<a>` – Creates a hyperlink to another page or resource.
* Important attribute: `href`.

### 5. Text Formatting Tags

* `<b>` – Displays text in bold without implying extra importance.
* `<i>` – Represents text in an alternate voice or mood, often displayed in italics.
* `<sub>` – Displays subscript text.
* `<sup>` – Displays superscript text.

### 6. List Tag

* `<ul>` – Creates an unordered list with bullet points.
* `<li>` – Defines an item inside a list.
