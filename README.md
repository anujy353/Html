Welcome to **Day 1 of my HTML learning journey!** 🚀

Today, I learned about basic HTML tags and how they are used to structure and format content on a web page.

## 📚 Topics Covered

### 1. Heading Tags

HTML provides six heading levels, from `<h1>` to `<h6>`.

* `<h1>` – Defines the highest-level heading.
* `<h2>` – Defines a second-level heading.
* `<h3>` – Defines a third-level heading.
* `<h4>` – Defines a fourth-level heading.
* `<h5>` – Defines a fifth-level heading.
* `<h6>` – Defines the lowest-level heading.

### 2. Paragraph Tag

* `<p>` – Defines a paragraph of text.

### 3. Image Tag

* `<img>` – Embeds an image into a web page.
* Important attributes: `src` and `alt`.

### 4. Anchor Tag

* `<a>` – Creates a hyperlink to another page or resource.
* Important attribute: `href`.

### 5. Text Formatting Tags

* `<b>` – Displays text in bold without implying extra importance.
* `<i>` – Represents text in an alternate voice or mood, often displayed in italics.
* `<sub>` – Displays subscript text.
* `<sup>` – Displays superscript text.

### 6. List Tag

* `<ul>` – Creates an unordered list with bullet points.
* `<li>` – Defines an item inside a list.

## 💻 Practice Code

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Day 1</title>
</head>
<body>

    <!-- Heading Tags -->
    <h1>Welcome to HTML</h1>
    <h2>HTML Learning Journey</h2>
    <h3>Day 1</h3>
    <h4>Basic Tags</h4>
    <h5>Practice</h5>
    <h6>Getting Started</h6>

    <!-- Paragraph Tag -->
    <p>I am learning HTML step by step.</p>

    <!-- Image Tag -->
    <img src="image.jpg" alt="Sample Image" width="200">

    <!-- Anchor Tag -->
    <a href="https://www.google.com">Visit Google</a>

    <!-- Text Formatting Tags -->
    <p>This is <b>bold</b> text.</p>
    <p>This is <i>italic</i> text.</p>
    <p>Water formula: H<sub>2</sub>O</p>
    <p>Square: x<sup>2</sup></p>

    <!-- Unordered List -->
    <ul>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
    </ul>

</body>
</html>
```
